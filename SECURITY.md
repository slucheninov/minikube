# Security Policy

## Supported versions

Only the latest release of `minikube.sh` is supported.

## Reporting a vulnerability

Please report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/slucheninov/minikube/security/advisories/new),
not in public issues. You should get a response within 7 days.

This is a local development tool: it manages Minikube clusters on your machine,
reads `~/.minikube.env` as data (never executes it) and does not run downloaded
installers.
